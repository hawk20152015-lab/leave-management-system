🚀 تحويل التطبيق إلى APK - دليل سريع
═══════════════════════════════════════════════════════════════════════════════════

📱 الملفات الأساسية:
────────────────────────────────────────────────────────────────────────────────

✅ app_kivy.py                    ← التطبيق الرئيسي (Kivy + Flask)
✅ buildozer.spec                 ← إعدادات البناء
✅ BUILD_APK_GUIDE.md             ← دليل مفصل
✅ build_apk.bat                  ← سكريبت Windows
✅ build_apk.sh                   ← سكريبت Linux/Mac
✅ requirements_apk.txt           ← المتطلبات

───────────────────────────────────────────────────────────────────────────────
⚡ الطريقة السريعة (Windows):
───────────────────────────────────────────────────────────────────────────────

1️⃣ انقر مرتين على:
   build_apk.bat

2️⃣ انتظر الانتهاء (10-15 دقيقة)

3️⃣ الملف سيكون في:
   bin/leavemgmt-1.0-debug.apk

───────────────────────────────────────────────────────────────────────────────
⚡ الطريقة السريعة (Linux/Mac):
───────────────────────────────────────────────────────────────────────────────

1️⃣ افتح Terminal وشغّل:
   chmod +x build_apk.sh
   ./build_apk.sh

2️⃣ انتظر الانتهاء

3️⃣ الملف سيكون في:
   bin/leavemgmt-1.0-debug.apk

───────────────────────────────────────────────────────────────────────────────
🔧 الطريقة اليدوية (جميع الأنظمة):
───────────────────────────────────────────────────────────────────────────────

# 1. فتح Terminal/CMD في مجلد المشروع

# 2. ثبّت المتطلبات (أول مرة)
pip install buildozer cython kivy flask

# 3. اختراق البناء
buildozer -u android debug

# 4. الملف يكون في:
# bin/leavemgmt-1.0-debug.apk

───────────────────────────────────────────────────────────────────────────────
✨ ما بعد البناء:
───────────────────────────────────────────────────────────────────────────────

📁 البحث عن الملف:
   Windows:  bin\leavemgmt-1.0-debug.apk
   Linux:    bin/leavemgmt-1.0-debug.apk
   Mac:      bin/leavemgmt-1.0-debug.apk

📱 التثبيت على الهاتف:
   1. انسخ الملف APK إلى الهاتف
   2. استخدم تطبيق البحث (File Manager)
   3. ابحث عن الملف وافتحه
   4. اضغط "Install"
   5. انتظر الانتهاء
   6. اضغط "Open" أو ابحث عن التطبيق بعد التثبيت

───────────────────────────────────────────────────────────────────────────────
🔐 الإعدادات على الهاتف:
───────────────────────────────────────────────────────────────────────────────

قد تحتاج إلى:
   Settings > Security > Unknown Sources > Enable

هذا يسمح بتثبيت تطبيقات من خارج Google Play Store

───────────────────────────────────────────────────────────────────────────────
🚨 الأخطاء الشائعة وحلولها:
───────────────────────────────────────────────────────────────────────────────

❌ "buildozer: command not found"
✅ الحل: pip install buildozer

❌ "Java not found"
✅ الحل: ثبّت Java JDK من Oracle

❌ "Android SDK not found"
✅ الحل: ثبّت Android Studio أو SDK

❌ "Cython compilation error"
✅ الحل: pip install --upgrade cython

❌ "Permission denied" (Linux/Mac)
✅ الحل: chmod +x build_apk.sh

───────────────────────────────────────────────────────────────────────────────
📊 معلومات البناء:
───────────────────────────────────────────────────────────────────────────────

وقت البناء:      10-30 دقيقة (أول مرة أطول)
حجم APK:        50-100 MB
متطلبات النظام: 2GB RAM على الأقل
مساحة القرص:     3GB على الأقل

───────────────────────────────────────────────────────────────────────────────
💡 نصائح مهمة:
───────────────────────────────────────────────────────────────────────────────

✓ استخدم Python 3.8 أو 3.9 (أكثر استقراراً)
✓ ثبّت جميع المتطلبات قبل البناء
✓ استخدم جهاز قوي للبناء الأول
✓ لا تقاطع عملية البناء
✓ تأكد من وجود 3GB مساحة حرة على القرص

───────────────────────────────────────────────────────────────────────────────
🎯 كيفية البناء بـ Release (للنشر):
───────────────────────────────────────────────────────────────────────────────

buildozer -u android release

سيطلب كلمات مرور، لكن Debug كافية للاختبار
