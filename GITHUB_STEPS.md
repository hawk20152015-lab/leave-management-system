1️⃣ إنشاء حساب GitHub
═══════════════════════════════════════════════════════════════════════════════

1. افتح: https://github.com/signup

2. أدخل:
   • البريد الإلكتروني
   • كلمة المرور
   • اسم المستخدم (username)

3. تأكيد البريد

4. انتهى! ✅

💡 سيكون رابط حسابك:
   https://github.com/USERNAME

═══════════════════════════════════════════════════════════════════════════════
2️⃣ تثبيت Git على Windows
═══════════════════════════════════════════════════════════════════════════════

الطريقة 1: تحميل مباشر
────────────────────────
1. افتح: https://git-scm.com
2. اضغط "Download for Windows"
3. ثبّت البرنامج (اقبل الإعدادات الافتراضية)

الطريقة 2: استخدام Chocolatey
──────────────────────────────
1. افتح PowerShell (Admin)
2. شغّل: choco install git
3. موافق على الرسالة

التحقق من التثبيت:
──────────────────
افتح PowerShell وشغّل:
   git --version

سيظهر: git version 2.x.x ✅

═══════════════════════════════════════════════════════════════════════════════
3️⃣ إنشاء Repository على GitHub
═══════════════════════════════════════════════════════════════════════════════

الخطوات:
────────

1. سجّل الدخول لـ GitHub

2. في الزاوية العلوية اليسرى، اضغط "+"

3. اختر "New repository"

4. ملء المعلومات:

   Repository name: leave-management-system
   
   Description: 
   تطبيق إدارة شامل للموظفين والإجازات والدوام الرسمي
   
   Visibility: 
   ⭐ Public (للمشاركة العامة)
   🔒 Private (خاص بك فقط)
   
   اختر: Public
   
   Initialize with:
   ✅ Add a .gitignore
      اختر: Python
   ✅ Add a license
      اختر: MIT License
   ❌ لا تختر README (سننشئه بأنفسنا)

5. اضغط "Create repository"

6. سيظهر الـ Repository الجديد!

الرابط سيكون:
   https://github.com/USERNAME/leave-management-system

═══════════════════════════════════════════════════════════════════════════════
4️⃣ رفع المشروع الأول (الخطوات الفعلية)
═══════════════════════════════════════════════════════════════════════════════

🔧 التهيئة الأولى:
─────────────────

1. افتح PowerShell في مجلد المشروع:
   
   cd C:\Path\To\leave_management_app_complete

2. أول مرة فقط - اضبط الإعدادات:

   git config --global user.name "اسمك الكامل"
   git config --global user.email "بريدك@gmail.com"
   
   مثال:
   git config --global user.name "عمر كريم"
   git config --global user.email "omar@example.com"

📤 رفع الملفات:
───────────────

1. تهيئة Git في المشروع:
   
   git init

2. أضف جميع الملفات:
   
   git add .

3. اكتب وصف أول commit:
   
   git commit -m "Initial commit - تطبيق إدارة الإجازات الكامل"

4. غيّر اسم الـ branch:
   
   git branch -M main

5. اربط مع GitHub (استبدل USERNAME):
   
   git remote add origin https://github.com/USERNAME/leave-management-system.git

6. رفع المشروع:
   
   git push -u origin main

7. قد يطلب اسم المستخدم والكلمة المرور:
   
   Username: USERNAME
   Password: (استخدم Personal Access Token، انظر الخطوة التالية)

💡 إذا قال "authentication failed":
   ────────────────────────────────
   
   1. افتح GitHub Settings:
      https://github.com/settings/tokens
   
   2. اضغط "Generate new token"
   
   3. اختر "repo" و "user"
   
   4. اضغط "Generate token"
   
   5. انسخ الـ Token
   
   6. استخدمه بدلاً من كلمة المرور

✅ النتيجة:
──────────
   Branch 'main' set up to track remote branch 'main' from 'origin'.

📍 الآن المشروع على GitHub! 🎉

═══════════════════════════════════════════════════════════════════════════════
5️⃣ بعد الرفع الأول - الدفع المستقبلية
═══════════════════════════════════════════════════════════════════════════════

كلما عملت تعديلات جديدة:
─────────────────────────

1. أضف التعديلات:
   git add .

2. اكتب وصف التعديل:
   git commit -m "وصف التعديل"
   
   أمثلة جيدة:
   git commit -m "إصلاح خطأ في حساب الإجازات"
   git commit -m "إضافة ميزة البدلاء"
   git commit -m "تحديث الواجهة"

3. رفع التعديل:
   git push

خلاص! ✅

6️⃣ الأوامر المهمة الأخرى
═══════════════════════════════════════════════════════════════════════════════

─────────────────────
git status

──────────────────────

───────────────────────

──────────────────────
git checkout اسم-الـ-branch

──────────────────────────────────────

──────────

git commit -m "حذف الملف"
git push

9️⃣ حل المشاكل الشائعة
═══════════════════════════════════════════════════════════════════════════════

❌ "fatal: not a git repository"
✅ تأكد من وجود مجلد .git
   git init

❌ "fatal: could not resolve host"
✅ تحقق من الإنترنت
   ping google.com

❌ "error: failed to push some refs"
✅ اسحب أولاً:
   git pull
   git push

❌ "fatal: Authentication failed"
✅ استخدم Personal Access Token (انظر الأعلى)
