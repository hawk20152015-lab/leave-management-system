# تطبيق رصيد الاجازات والدوام
## Leave and Shift Management Application

تطبيق متقدم لإدارة رصيد الاجازات والدوام والخفر للموظفين في المؤسسات العراقية.

---

## المميزات الرئيسية

### 1️⃣ إدارة الموظفين
- ✅ إضافة/تعديل/حذف الموظفين
- ✅ تحديد نوع الدوام (صباحي/مسائي)
- ✅ تحديد البديل (المعاكس) لكل موظف
- ✅ تاريخ التعيين والمنصب

### 2️⃣ نظام حساب الدوام
#### الدوام الصباحي (يومي):
- يعمل كل يوم ما عدا **الجمعة والسبت**
- يتم استثناء **الأعطال الرسمية**
- **مشمول** بالأعطال الرسمية (يُخصم من الرصيد)

#### الخفر (مسائي):
- يعمل طول السنة **ما عدا الجمعة والسبت فقط**
- **لا يتم** استثناء الأعطال الرسمية
- **غير مشمول** بالأعطال الرسمية
- لكل موظف خفر وجبة محددة وبديل معاكس

### 3️⃣ حساب الرصيد السنوي
- **الدوام الصباحي**: 30 يوم إجازة سنوية
- **الخفر**: لا يأخذ إجازات
- تتبع الإجازات المأخوذة
- حساب الرصيد المتبقي تلقائياً
- تقارير تفصيلية للرصيد

### 4️⃣ الأعطال الرسمية المدمجة
التطبيق يحتوي على الأعطال الرسمية العراقية:
- رأس السنة الميلادية (1 يناير)
- يوم الشهيد (1 فبراير)
- عيد الفلاح (11 فبراير)
- نوروز (20 مارس)
- عيد الحب (9 أبريل)
- عيد العمال (10 أبريل)
- عيد الأم (1 مايو)
- ذكرى ثورة 14 تموز (17 يوليو)
- عيد الاستقلال (15 أغسطس)

## البنية الأساسية

### قاعدة البيانات:
التطبيق يستخدم SQLite ويحتوي على الجداول التالية:

#### 1. جدول الموظفين (employees)
```sql
- id: معرف الموظف
- name: الاسم
- position: المنصب
- hire_date: تاريخ التعيين
- shift_type: نوع الدوام (صباحي/مسائي)
- backup_employee_id: معرف الموظف البديل
- status: حالة الموظف
- annual_leave_balance: رصيد الإجازات السنوي
- sick_leave_balance: رصيد الإجازات المرضية
- unpaid_leave_balance: رصيد الإجازات بدون راتب
```

#### 2. جدول أيام الدوام (shift_days)
```sql
- id: معرف
- date: التاريخ
- employee_id: معرف الموظف
- shift_type: نوع الوجبة
- is_backup: هل هو بديل؟
- is_holiday: هل هي عطلة رسمية؟
- notes: ملاحظات
```

#### 3. جدول طلبات الإجازات (leave_requests)
```sql
- id: معرف الطلب
- employee_id: معرف الموظف
- leave_type: نوع الإجازة
- start_date: تاريخ البداية
- end_date: تاريخ النهاية
- days: عدد الأيام
- status: حالة الطلب (معلق/موافق/مرفوض)
- notes: ملاحظات
```

#### 4. جدول الأعطال الرسمية (holidays)
```sql
- id: معرف
- date: التاريخ
- holiday_name: اسم العطلة
- holiday_type: نوع العطلة (رسمي/ديني/etc)
```

## الواجهات

### 1. تبويب الموظفين
- قائمة بجميع الموظفين
- إضافة موظف جديد
- تعديل البيانات
- حذف الموظف

### 2. تبويب رصيد الإجازات
- جدول تفصيلي للرصيد
- عرض حسب السنة
- الرصيد الأساسي / المأخوذ / المتبقي
- أيام الدوام الفعلية

### 3. تبويب أيام الدوام
- إحصائيات الدوام الصباحي والخفر
- عرض حسب الموظف والسنة
- تفاصيل الوجبات والبدلاء

### 4. تبويب الإجازات
- إدارة طلبات الإجازات
- تتبع حالة الطلبات
- الموافقة/الرفض

## الحسابات والصيغ

### حساب أيام الدوام الصباحي:
```
أيام الدوام الصباحي = إجمالي أيام السنة 
                    - الجمعات والسبتات
                    - الأعطال الرسمية
                    - الإجازات المأخوذة
```

### حساب أيام الخفر:
```
أيام الخفر = إجمالي أيام السنة 
           - الجمعات والسبتات
           (الأعطال الرسمية لا تُستثنى)
```

### حساب رصيد الإجازات:
```
الرصيد المتبقي = الرصيد الأساسي (30) - الإجازات المأخوذة
```

## الاستثناءات والحالات الخاصة

### الجمعة والسبت:
- **الدوام الصباحي**: عطلة نهاية أسبوع
- **الخفر**: عطلة نهاية أسبوع

### الأعطال الرسمية:
- **الدوام الصباحي**: مشمول (يُخصم من الرصيد)
- **الخفر**: غير مشمول (لا يُخصم من الرصيد)

### الموظفون والبدلاء:
- كل موظف خفر له بديل معاكس
- البديل يعمل في الوجبة المعاكسة
- يجب تحديد البديل عند إضافة الموظف
